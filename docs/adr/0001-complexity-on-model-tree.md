# 复杂度按模型树统计

rescale=True 时 sklearn 包装器会把模型树里每处变量替换成 a*x+b 以映射回原始尺度，每处变量出现净增 4 个前缀节点，且 a、b 是长浮点常数，导致节点数复杂度虚高约一半。决定复杂度一律按标准化输入空间的模型树统计，逆标准化常数不计入，已产出的两份 CSV 按 complexity - 4*变量出现次数 精确换算修正。

## Considered Options

- 源头保留模型树供复杂度统计（采纳，口径干净且不依赖实现细节）
- 推理脚本里按 4*变量出现次数扣减（放弃，依赖 rescale 实现的隐含契约）
- 只在汇总脚本里扣减（放弃，CSV 本身仍是错的）

## Consequences

- expr 列继续保存原尺度表达式，含缩放常数，与 complexity 口径不同
- pmlb_true_expr_complexity 的真值复杂度口径不变，与修正后的模型复杂度直接可比
